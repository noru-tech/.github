# Support

Thanks for using Noru! Here's how to get help depending on what you need.

## 💬 Questions & Discussions

For how-to questions, ideas, and general discussion about our open repositories, please use
**GitHub Discussions** (where enabled) or open an issue in the relevant repository.

Before opening a new issue or discussion:

1. Search existing issues and discussions — your question may already be answered.
2. Check the documentation linked above.

## 🐛 Bugs & Feature Requests

- **Bug?** Open an issue using the bug report template in the affected repository.
- **Feature idea?** Open an issue using the feature request template.

## 🔒 Security Issues

Do **not** use public issues for security reports. Please follow our
[Security Policy](SECURITY.md).

## 🏢 Customers & Commercial Support

If you're a Noru customer and need help with your compliance program, account, or the
hosted platform, please use your dedicated support channel or the contact options on
https://noru.tech. GitHub is intended for our open-source repositories and is **not** a
channel for sensitive account, audit, or compliance data.

> ⚠️ Never post secrets, credentials, customer data, or audit evidence in a public issue,
> discussion, or pull request.
